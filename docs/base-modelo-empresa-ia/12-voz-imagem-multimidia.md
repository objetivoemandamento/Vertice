# 12 — Voz, Imagem e Multimídia

## Voz
- Whisper/faster-whisper: transcrição.
- Kokoro: síntese de voz local.

## Imagem
- FLUX: geração de imagens open-weight/open source conforme a variante/licença.

## Pipeline
Briefing → roteiro → texto → imagem/vídeo → voz → composição → QA → publicação.

## Aplicações
Marketing, treinamento, atendimento, documentação, apresentações, demonstrações de produto e conteúdo.

## Regra
Ativos de marca e direitos de terceiros devem ser tratados como dados governados, não como material automaticamente livre para reutilização.
