# 08 — Dados e Documentos

## Componentes
- Supabase/Postgres: núcleo transacional.
- PandasAI: análise de dados orientada por linguagem.
- MinerU: transformação de documentos em conteúdo estruturado.
- OCR: extração de texto de documentos e imagens.

## Funções
- leitura de contratos;
- extração de dados;
- análise de planilhas;
- relatórios;
- indicadores;
- reconciliação;
- preparação de contexto para agentes.

## Princípio
Cálculos críticos devem ser determinísticos no código. A IA interpreta os resultados; não deve substituir a lógica financeira ou contábil.
