# 07 — Navegador e Computador

## Browser
Browser Use pode funcionar como camada de execução para agentes que precisam navegar na web.

## Computer Use
UI-TARS é uma referência para interação com interfaces gráficas e cenários de computador/mobile.

## Casos
- preencher formulários;
- operar dashboards;
- consultar sistemas;
- coletar informações;
- testar interfaces;
- executar rotinas administrativas.

## Segurança
Navegação autenticada, compras, alterações de conta, ações financeiras e operações destrutivas devem passar por permissões específicas e registro de auditoria.
