# Base do Modelo de Empresa Operada por IA — VÉRTICE

Esta pasta reúne a base conceitual e técnica para a futura introdução do VÉRTICE como uma empresa com uma IA central e agentes especialistas.

## Princípio
O VÉRTICE não será uma coleção de chatbots isolados. Será uma arquitetura empresarial na qual:
- uma IA central coordena estratégia e decisões;
- modelos especializados executam funções específicas;
- agentes usam ferramentas reais;
- memória e conhecimento são persistentes;
- ações passam por políticas, permissões e auditoria;
- modelos podem ser substituídos sem reescrever o núcleo.

## Critério de seleção
Prioridade para modelos open-weight/self-hosted e projetos open source maduros. Modelos fechados podem ser usados quando agregarem capacidade excepcional, mas devem ficar atrás de um gateway de modelos.

## Regra de arquitetura
IA → Validador → Policy Engine → Sandbox/Tool → Resultado → Auditoria.

As referências externas devem ser tratadas como componentes substituíveis, não como dependências conceituais permanentes.
