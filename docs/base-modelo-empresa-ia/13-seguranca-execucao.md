# 13 — Segurança e Execução

## Princípio
Autonomia não significa acesso irrestrito.

## Camadas
1. autenticação;
2. autorização;
3. policy engine;
4. sandbox;
5. ferramentas com escopo mínimo;
6. auditoria;
7. aprovação quando necessário.

## OpenShell
É uma referência para ambientes de execução controlados para agentes.

## Ações de alto impacto
- produção;
- banco de dados;
- credenciais;
- pagamentos;
- exclusões;
- publicação;
- contratação;
- alterações jurídicas.

Essas ações devem possuir controles adicionais.

## Objetivo
Permitir que o agente seja altamente autônomo dentro de um perímetro tecnicamente definido.
