# 05 — Memória e Conhecimento

## Componentes
- Letta: agentes com estado e memória persistente.
- Graphiti: conhecimento temporal/relacional.
- RAG: recuperação de documentos.
- Supabase/Postgres: dados transacionais e conhecimento estruturado.

## Tipos de memória
### Episódica
O que aconteceu.

### Semântica
O que o VÉRTICE sabe.

### Procedural
Como determinada tarefa deve ser executada.

### Organizacional
Decisões, políticas, contratos, clientes, projetos e histórico.

## Princípio
Memória não deve ser apenas um prompt gigante. Deve ser estruturada, recuperável, atualizável e auditável.
