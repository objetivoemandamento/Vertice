# 06 — Pesquisa e Inteligência

## Componentes
- GPT Researcher: pesquisa web multi-etapa.
- Browser Use: navegação automatizada.
- Kimi/GLM/Qwen/DeepSeek: síntese e raciocínio.

## Funções
- pesquisa de mercado;
- inteligência competitiva;
- monitoramento de produtos;
- análise de tendências;
- pesquisa técnica;
- levantamento de fornecedores;
- due diligence documental.

## Fluxo
Pergunta → planejamento → coleta → deduplicação → avaliação de fontes → síntese → evidências → relatório → decisão.

## Regra
A IA deve diferenciar fato, inferência e hipótese e registrar as fontes utilizadas.
